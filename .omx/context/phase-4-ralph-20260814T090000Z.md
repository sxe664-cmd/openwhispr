# Slice 4 Ralph Handoff

## Scope completed

- Added local encounter output persistence keyed by encounter, with independent Summary and SOAP statuses, transcript hashes, provider/model metadata, stale detection, and retry transitions.
- Added final encounter recording completion so the canonical note transcript is saved before the encounter is marked completed.
- Added recording ownership guards so an encounter cannot silently attach to another encounter's active recording.
- Added local/BYOK-only clinical generation using the existing reasoning service. Local mode is the default; BYOK requires an explicit provider/model and never falls back to a hosted route.
- Added encounter Summary/SOAP tabs and status/retry UI while preserving the raw transcript and existing quick-dictation behavior.
- Added the required clinical-output locale keys to all supported locales.
