# Phase 3 Ralplan Correction 2: Safe Sidecar Errors

## Scope

Close Terra Review 2's P1 finding without changing encounter, calendar-link, transcription, or Phase 4 behavior.

## Contract

Renderer-facing AIReceptionist failures must be `{ code, message }` using a fixed local code/message map. Raw stderr/stdout, exception text, command arguments, paths, environment values, JSON credential fields, bearer/API tokens, cookies, passwords, and OAuth material never cross the runtime/IPC boundary. Operational logs may retain only the operation and stable code.

## Work package

Route to Terra High. Limit changes to `aiReceptionistRuntime.js`, `receptionistCalendarBridge.js`, relevant AIReceptionist IPC/type/UI status surfaces, and focused runtime/bridge/UI tests. Preserve stale cached encounters and existing status transitions; use generic actionable copy for unavailable, timeout, command failure, invalid response, and agent failures.

## Acceptance

- Failed sidecar output containing Windows/macOS paths, `.env.local`, JSON OAuth fields, bearer/API tokens, cookies, or command args produces none of those values in renderer-facing results/status/UI.
- Calendar feed, malformed response, reminder, and agent failures retain stable codes and cached/offline behavior.
- Existing Phase 3 link/reconciliation tests and full regression suite remain green.
